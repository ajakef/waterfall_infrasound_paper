TITLE


Infrasound from Niagara Falls



IDENTIFIER



SUMMARY AND PURPOSE


This dataset includes infrasound recorded near this waterfall, originally for a paper by Anderson, Ortiz, and Barber on waterfall infrasound.

DATE(S) 


Time Period Covered by Data: 202408-202409

Update Frequency:  At regular intervals such as monthly or annually


 
LIST OF FILES RELATED THE STUDY

One folder of miniSEED files:
. 2024_infrasound_miniSEED

One folder of csv files containing station positions over time:
. NiagaraFalls_GPS

coords_Niagara.csv, containing station coordinates from 20240918_00:00-20240920_12:00. All sensors in this csv file were stationary during that interval. Sensor tracks for the full recording period are given in the files in NiagaraFalls_GPS.

INCHourly_Aug-Sep2024.csv, containing discharge data for water going over the falls (i.e., not diverted through the nearby power plants). Data file provided by International Niagara Board of Control.

FILE FORMATS 

miniSEED, csv



DATA ATTRIBUTES 


Infrasound (miniSEED) was recorded using Gem infrasound loggers.
